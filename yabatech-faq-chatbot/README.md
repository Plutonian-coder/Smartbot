# Yabatech FAQ Chatbot

This is a Streamlit application that provides a simple FAQ chatbot for Yabatech.

## Setup

1.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Add assets:**
    -   Place a Yabatech campus image at `assets/yabatech.jpg`.
    -   Place the Yabatech logo at `assets/logo.png`.

## Running the App

To run the app, navigate to the `yabatech-faq-chatbot` directory and run the following command:

```bash
streamlit run src/main.py
```

The app will open in your browser. You can navigate to the "Chat" page from the sidebar to start a conversation with the bot.
